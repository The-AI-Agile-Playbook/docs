AI Assistants (LLMs)

ChatGPT (OpenAI) Visit

The most widely adopted LLM. GPT-4o offers strong reasoning, code interpretation, and image analysis. Custom GPTs let you create pre-configured assistants for recurring tasks like retro planning or story analysis.

SM Use Case 
Key features for Scrum Masters:
- Custom GPTs for recurring ceremony design
- Code Interpreter for analyzing sprint data (CSV uploads)
- DALL-E for creating visual facilitation boards
- Memory feature to retain team context across sessions
- Canvas mode for collaborative document editing

Best for: Story refinement, retro design, coaching prep, data analysis
Free + $20/mo Cognitive Layer General Purpose
Claude (Anthropic) Visit

Known for nuanced reasoning, longer context windows (200K tokens), and strong performance on complex analytical tasks. Excels at processing large documents like meeting transcripts and multi-sprint data. Projects feature maintains context across conversations.

SM Use Case 
Key features for Scrum Masters:
- 200K context window — paste entire sprint backlogs or long transcripts
- Projects — save team context, DoD, and ceremony templates for reuse
- Artifacts — generates standalone documents, tables, and code
- Strong coaching simulation and conflict resolution scenarios
- Less prone to "sycophantic" responses — gives honest feedback

Best for: Deep analysis, long documents, coaching prep, honest assessments
Free + $20/mo Cognitive Layer Deep Analysis

SM Use Case

- Auto-generate meeting notes in Google Meet

Free + $20/mo Cognitive Layer Workspace Integration

Automation & Async Communication

Geekbot Visit

Async standup bot for Slack and Microsoft Teams. Collects structured updates at scheduled times, compiles reports, and flags blockers. The #1 tool for replacing status-update standups with async text check-ins.

Setup Guide 
Geekbot async standup setup:
1. Install in Slack or Teams
2. Configure questions:
   - "What will you focus on today?"
   - "Any blockers or risks?"
   - "Anything the team should know?"
3. Set schedule: Daily at 9:00 AM team timezone
4. Set response deadline: 9:30 AM
5. Auto-post summary to team channel

Pro tip: Add a weekly Friday question:
"Rate your week 1-5 and one word to describe it"
— instant pulse survey, zero extra tools
Free + $3.50/user/mo Async Standups Slack/Teams
Zapier Visit

No-code automation platform connecting 6,000+ apps. Build workflows that eliminate manual tasks: auto-create Jira tickets from Slack messages, sync meeting notes to Confluence, or trigger sprint reports on a schedule.

SM Automation Ideas 
Zapier automations for Scrum Masters:

1. Slack message → Jira ticket
   "When someone posts in #bugs channel, create a Jira bug"

2. Sprint end → Automated report
   "Every other Friday, export Jira data and email summary"

3. PR merged → Slack notification
   "When PR merges to main, notify #releases channel"

4. Calendar event → Prep reminder
   "1 hour before Retro, send me the prep checklist"

5. New Jira blocker → Manager alert
   "When a story is flagged as blocked, DM the SM and PO"

6. Otter transcript → Confluence page
   "After every meeting, save notes to Confluence automatically"
Free + $20/mo No-Code 6000+ Integrations
Slack Workflow Builder Visit

Built-in Slack automation for creating custom workflows without code. Create standup bots, approval processes, and data collection forms. If your team already uses Slack, this is the zero-cost automation starting point.

SM Workflow Ideas 
Slack Workflow ideas for Scrum Masters:

1. Daily async standup
   Trigger: Schedule (9 AM) → Form: 3 questions → Post to channel

2. Impediment escalation
   Trigger: Emoji reaction (🚫) on message → DM to SM + create Jira ticket

3. Sprint retrospective input collector
   Trigger: Friday 3 PM → Form: What went well / What didn't → Save to channel

4. New team member onboarding
   Trigger: User joins channel → Send welcome message with links to DoD, ceremonies calendar, team norms

5. Meeting decision logger
   Trigger: Slash command /decision → Form → Post to #decisions channel
