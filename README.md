# The AI-Agile Playbook — Digital Companion

This is the digital companion site for **The AI-Agile Playbook**, a 20-day workbook for Scrum Masters who refuse to become obsolete.

## Live Site

The site is deployed via GitHub Pages at the `/docs` folder.

## Pages

| Page | Description |
|------|-------------|
| [index.html](index.html) | Landing page — book overview, curriculum, and links to resources |
| [scrum-master-prompts-lib.html](scrum-master-prompts-lib.html) | 31 battle-tested AI prompts organized in 11 categories |
| [scrum-master-ai-tools.html](scrum-master-ai-tools.html) | 30+ curated AI tools for Scrum Masters in 9 categories |

## Structure

```
docs/
  index.html                    # Landing page
  scrum-master-prompts-lib.html # Prompt library (11 categories, 31 prompts)
  scrum-master-ai-tools.html    # AI tool catalog (9 categories, 30+ tools)
  README.md                     # This file
```

## Tech Stack

- Pure HTML/CSS/JS — no build step, no dependencies
- Inter font (Google Fonts)
- Font Awesome 6.5 icons
- Dark theme design system with CSS custom properties
- Fully responsive (mobile, tablet, desktop)

## Deploying

To deploy via GitHub Pages:

1. Go to repository **Settings > Pages**
2. Set source to **Deploy from a branch**
3. Select **main** branch and **/docs** folder
4. Save — the site will be live at `https://<username>.github.io/<repo>/`
